# Porta-Browser-Desktop
Just. Simple. Browsing. 

Now also for Linux. This code should also be compatible with some modifications wirh Windows & MacOS. But I don´t use these systems. So feel free to compile it for your system!

A few weeks ago I started making <a href=https://github.com/Joshi7479/Porta-Browser>my own Andoid Browser.</a>
And now I started rewriting it in C++ for Linux with QT and QTWebEgine (basedon Chromium). The focus is on having not to much features but to make it fast. I think it is really good to use on old hardware. 

But:
This Browser is in a really early state. So a few things might not work (as expected)!

How to install?
For Debian based distros (like Mint or Ubuntu):
1. Download the .deb.
2. Open a Terminal in the directory where the .deb is.
3. Execute: sudo apt install {file-name.deb}
4. Ready!

For Fedora based distros (like Nobara or Bazzite):
1. Download the .rpm
2. Double click the file to install.

For Arch based Distros (like CachyOS or EndeavourOS):
1. Download the .tar.gz
2. Extract it into a new directory.
3. Open a terminal in the new directory.
4. Execute make.
5. -> sudo make install.
